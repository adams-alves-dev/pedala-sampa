O bug

clip-path recorta o box-shadow

O hover do CTA amarelo simplesmente não aparecia. A sombra era desenhada e cortada no mesmo frame.

Sobrava só o deslocamento de 2px. Imperceptível.

/* o elemento é cortado em paralelogramo... */ .ps-cta { clip-path: polygon(16px 0, 100% 0, ...); } /* ...e a sombra do hover nasce já cortada */ .ps-cta:hover { box-shadow: 4px 4px 0 var(--green); /* ✗ */ }

Recorte e sombra vivem em estágios diferentes do pipeline de pintura.

Duas tentativas

A primeira correção também falhou

✗ Tentativa 1

filter: drop-shadow()

Aplicado depois do recorte — deveria funcionar. Mas não renderiza sobre clip-path em alguns navegadores.

✓ Solução

Camadas na mão

Parar de pedir sombra ao browser e construir a camada como elemento real.

.ps-cta { isolation: isolate; /* escopa o z-index negativo */ } .ps-cta::after { /* face amarela */ } .ps-cta::before { /* bloco verde atrás dela */ z-index: -1; } .ps-cta:hover::before { transform: translate(4px, 4px); /* ✓ desliza */ }

Sem filter. Sem box-shadow recortado. Confiável cross-browser.
