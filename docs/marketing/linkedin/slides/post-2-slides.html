O que mais o sistema fecha

Pouca escolha, de propósito

Tipo Escala fechada, de 11px a um clamp que chega a 80px
Espaço Base 4px — de 4 a 64
Raio Dois. 4px e 6px.
Sombra Duas: a de placa (4px 4px 0, sem blur) e a de painel (essa sim, difusa)
Fonte Archivo para display, Hanken Grotesk para corpo

Sistema pequeno não é sistema pobre. É sistema que alguém consegue seguir sem consultar documentação toda vez.

E o painel de tweaks?

Ajustava os tokens ao vivo. Estava pronto. Não foi.

Explorar seis e escolher dois não é desperdício — é como você descobre que dois bastam.

O desperdício seria implementar os seis porque já estavam prontos.
