Por que um grupo novo no CMS dá 404 — e por que isso não é bug.

Arraste →

Os dois caminhos do dado

Leitura vai direto. Escrita, nunca.

Leitura

browser → CMS

Endpoint público, token read-only. Não precisa de servidor no meio.

Escrita

browser → server route → CMS

Todo POST passa por uma função. Sempre.

// composables/useSuggestions.ts // o token de escrita NÃO pode existir no bundle // do client — por isso nunca vai direto ao CMS

A regra está escrita como comentário, para ninguém "otimizar" isso depois.

O problema

Ele descobriu as rotas no build

O Nuxt roda o prerender com crawlLinks: começa na home, segue todos os links e gera um HTML para cada rota que encontrou.

1 Build roda. Crawler visita a home e segue os links.

↓

2 Um HTML é gerado por rota descoberta. Site no ar, rápido.

↓

3 Grupo novo publicado no CMS. O crawler nunca passou por essa rota.

↓

4 404. O arquivo não existe no dist.

A solução

E ela não está no repositório

1 Conteúdo publicado no Hygraph

↓

2 Webhook dispara o build hook da Netlify

↓

3 Build roda de novo. Agora a rota existe.

Por que virou documentação

É infraestrutura invisível no código e requisito absoluto de funcionamento. Exatamente o tipo de coisa que some quando alguém assume o projeto.

Cache

Cada miss custa uma chamada autenticada

// server/api/groups/[slug].get.ts setResponseHeader(event, 'Cache-Control', 'public, max-age=60, s-maxage=300, stale-while-revalidate=600' )

max-age=60

O formulário de correção não precisa de dado fresquíssimo.

s-maxage=300

O CDN segura por 5 minutos e absorve o pico.

stale-while-revalidate=600

Ninguém espera revalidação. Serve o velho, atualiza atrás.

Leaflet × SSR

Duas armadilhas que custaram tempo

1

Import como valor quebra o SSR

O Leaflet toca em window na avaliação do módulo. No escopo do módulo só entram tipos; o import real é tardio.

2

Estilo do pin não pode ser scoped

O Leaflet renderiza marcadores fora da árvore do componente. O atributo de escopo do Vue nunca chega neles.

Se eu mudasse uma coisa hoje

Trocar o rebuild inteiro por ISR via routeRules. Publicar um grupo não deveria custar um build do site todo.
